# The Bago Block Gazette

Automated newspaper and permanent record book for **Bago Block v3**, a 12-team ESPN fantasy-football league.

## Automated Tuesday pipeline
1. Collect public ESPN league data.
2. Preserve raw timestamped snapshots.
3. Calculate weekly awards.
4. Update historical game records.
5. Analyze standings and scoring.
6. Generate the weekly Gazette.
7. Build the newspaper-style web edition.
8. Commit the database and publication back to this repository.

## Publication
- `gazette/latest.md` — current issue
- `gazette/week-N.md` — permanent weekly issues
- `site/index.html` — newspaper-style edition
- `data/history.json` — independent historical record
- `data/2026/` — raw and derived 2026 league data
